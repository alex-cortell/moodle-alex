# Proyecto Moodle - Hacking Ético

## Descripción
Proyecto de instalación y configuración de Moodle utilizando Docker para crear un curso sobre hacking ético y ciberseguridad.

## Tecnologías utilizadas
- Moodle
- Docker y Docker Compose
- PHP
- MariaDB
- Git y GitHub

## Contenido del curso
- Introducción al hacking ético
- Detección de phishing
- Protección de un ordenador
- Test de hacking ético y ciberseguridad
- Proyecto final de auditoría de seguridad informática
- Teoría para cada tema
- Vídeos explicativos
- Recursos adicionales para cada tema
- 10 actividades ordenadas por dificultad
- Rúbrica de evaluación para valorar las actividades

## Copia de seguridad
Se incluye una copia de seguridad del curso en formato `.mbz`, que permite restaurarlo en otra instalación de Moodle.

Archivo: `copia_de_seguridad-moodle2-course-2-hacking_etico-20261022-0939.mbz`

## Instalación
1. Instalar Docker Desktop.
2. Descargar o clonar este repositorio.
3. Abrir una terminal en la carpeta del proyecto.
4. Iniciar los contenedores con Docker Compose:

```bash
docker compose up -d
```

5. Entrar en Moodle desde el navegador:

http://localhost:8080
