Proyecto Moodle - Hacking Ético

Descripción

Proyecto de instalación y configuración de Moodle utilizando Docker para crear un curso sobre hacking ético y ciberseguridad.

Tecnologías utilizadas

Moodle

Docker y Docker Compose

PHP

MariaDB

Git y GitHub

Introducción al hacking ético

Detección de phishing

Test de hacking ético y ciberseguridad

Proyecto final de auditoría de seguridad informática

Vídeos explicativos

Recursos adicionales para cada tema

Instalación

Instalar Docker Desktop.

Descargar o clonar este repositorio.

Abrir una terminal en la carpeta del proyecto.

Iniciar los contenedores con Docker Compose:

docker compose up -d

Entrar en Moodle desde el navegador:

http://localhost:8080
